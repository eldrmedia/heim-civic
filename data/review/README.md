# Review artifacts

This directory contains reproducible source audits that require an explicit
editorial or product decision before their records can enter a public snapshot.
Artifacts retain authoritative source URLs, retrieval times, and document
hashes; they are not public civic records by themselves.

`phase-9-3-final-coverage-audit.json` is the reproducible FR-007 through FR-009
integrity report for the currently published enhanced Nevada set. An
`action-required` status means the evidence package is valid but at least one
publication-governance requirement remains open; it must not be read as a human
approval decision.
