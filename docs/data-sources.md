## Discovery exit criteria

- Representative fixtures exist for success, ambiguity, missing fields, schema changes, and historical updates.
- External identifiers are namespaced and stable enough for idempotent imports.
- Each adapter has an owner, cadence, parser version, health signal, and last-known-good behavior.
- Publication stops on unexpected schemas, topology failures, count changes, or reconciliation errors.
- Exact residential addresses are absent from fixtures and diagnostic output.

## Phase 4 legislation snapshot

The pilot snapshot is generated by `npm run data:legislation` from `data/sources/pilot-legislation.manifest.json`. The builder downloads seven official records: four NELIS fragments for Nevada AB83, GovInfo BILLSTATUS XML for H.R. 1366, and two U.S. House Clerk roll-call XML files. It retains source hashes, retrieval times, parser version, official wording, original vote values, and normalized vote values.

The snapshot intentionally contains exactly two bills and four recorded votes. Publication stops on missing bill coverage, unexpected vote counts, NELIS member-count disagreement, or incomplete Nevada House delegation reconciliation. A historical Nevada lawmaker is not forced onto a current profile when identities do not reconcile. See decision record `0004-pilot-legislation-snapshot.md`.

## Phase 9.1 complete bill index

`npm run data:bill-index` downloads the official NELIS Assembly Bill and Senate
Bill listings with official titles enabled and requests each chamber's complete
result set. The generated artifact contains 1,152 source-listed records: 623
Assembly and 529 Senate. It preserves 43 identifiers carrying an unexplained
NELIS asterisk and does not interpret that marker.

The builder validates expected source totals, standard and source-marked counts,
bill-type identifiers, stable numeric keys, unique displayed identifiers,
official HTTPS URLs, nonempty synopses and long titles, source hashes, and all 86
veto-audit joins. Index-only records link to NELIS; they do not claim local
status, sponsor, action, committee, summary, or vote completeness. See decision
record `0007-complete-bill-index-and-enhanced-coverage.md`.

## Phase 7 selection audit

## Phase 9.2 enhanced-review queue

`npm run data:enhanced-bill-review` reads the manually curated first-batch
manifest, reconciles every identifier and numeric bill key against both the
complete bill index and official veto audit, then downloads the NELIS overview,
history, sponsor, committee, final-vote summary, and member-vote fragments. The
current package contains ten bills across the ten PRD subject areas, 21 recorded
roll calls, and 41 checksummed official source documents.

The generated state is `awaiting-human-review`. The builder verifies official
digests, veto actions, source hashes, vote totals, member counts, and at least one
current-profile reconciliation per vote, but it cannot approve editorial copy,
interpret repeated vote labels, assess material amendments, or promote a local
enhanced page. See `docs/phase-9-2-enhanced-bill-review.md`.

## Phase 9.3 Batch 2 expansion

`npm run data:enhanced-bill-review:batch-2` selects the next ten unprocessed
governor-veto qualifiers in ascending bill-identifier order, validates that
order against the checked-in veto audit, and writes a separate immutable review
bundle. The package contains ten bills, 20 reconciled roll calls, and 40

log. All ten records passed accountable review and matching-fingerprint
promotion on August 24, 2026; AB82 and AB98 retain their documented sponsor-role

`npm run data:editorial-review-packets:batch-2` writes the corresponding
vote-level review packets. The AI-assisted evidence assessment also compares all
ten official digests with the enrolled PDFs; recommendations are not editorial
decisions. See `docs/phase-9-3-enhanced-coverage-expansion.md`.

## Phase 5 finance snapshot

The federal pilot snapshot is generated by `npm run data:finance` from `data/sources/pilot-finance.manifest.json`. It uses documented FEC candidate-totals and principal-committee API records for Mark Amodei and Steven Horsford. The checked-in result retains coverage dates, report type, official FEC categories, candidate and committee IDs, retrieval times, source hashes, and parser version.

Publication stops on missing records, identity disagreement, an unexpected election cycle, invalid amounts, or contribution-category reconciliation failure. The snapshot excludes contributor lists, outside spending, and Nevada state campaign finance. The source audit found that public AURORA access requires a human challenge and warns that automated traffic is prohibited; the product will not bypass that control. See decision record `0005-federal-finance-pilot.md`.
